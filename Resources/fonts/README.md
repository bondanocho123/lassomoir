# Font tertanam

Font antarmuka yang bisa dipilih lewat **⚙ → Ganti font…**. File `.ttf` (tebal 400 dan 700) diunduh dari Google Fonts (`fonts.gstatic.com`) pada 1 Oktober 2026 dan didaftarkan saat aplikasi mulai (`AppFonts::registerBundled`).

Font bawaan aplikasi tetap **Garamond** dari `styles.qss`. Font di bawah ini hanya pilihan tambahan.
